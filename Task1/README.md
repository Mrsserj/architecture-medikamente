# Задание 1

## 1. Аудит мер по обеспечению безопасности данных

### Проблемные зоны

1. Хранение данных
    - Пользовательские данные хранятся в открытом виде
    - Отсутствует шифрование и защита данных
    - Ручная обработка увеличивает риск ошибок в исходных данных
    - Отсутствует резервное копирование

2. Контроль доступа
    - Отсутствует ролевая модель доступа к данным
    - Отсутствует аутентификация к данным

3. Мониторинг и аудит
    - Действия с данными не логируются.
    - Отсутствуют метрики и нет аудита системы

4. Требования по законодательству
    - Нет механизма удаления данных по запросу (GDPR/ФЗ-152)
    - Отсутствуют сроки хранения данных

## 2. Что можно улучшить

1. Классификация данных: публичные, внутренние, конфиденциальные.

2. Защита данных
    - конфиденциальные данные: шифрование
    - внутренние данные: обфускация
    - публичные данные: обезличивание 

3. Система контроля доступа 
    - аутентификации и авторизации посредством использования Active Directory
    - использование модели RBAC.
    - ограничить доступ сотрудникам исходя из принципа наименьших привилегий
    - Внедрить двухфакторную авторизацию

4. Аудит и мониторинг
    -  Внедрить механизмы логирования и контроля потока данных во внутренней сети.

5. Система хранения
    - Миграция данных в защищенную БД с механизмами шифрования
    - Резервное копирование

6. Документация и обучение персонала
    - Правила и инструкции по работе с данными
    - Обучение сотрудников при работе с данными
